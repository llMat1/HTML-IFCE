# Atividades de HTML — IFCE

Repositório destinado às listas e atividades de HTML desenvolvidas durante o Curso Técnico em Informática do IFCE — Campus Maranguape.

As atividades deste repositório foram propostas pelo professor Thomaz Maia, como parte dos estudos de desenvolvimento web.

Aqui estão armazenadas as atividades desenvolvidas durante o curso:

* **Atividade 1:** `<html`, `<head>`, `<body>`, `<footer>`
* **Atividade 2:** `<main>`, `<section>`, `<aside>`
* **Atividade 3:** `<h1>`, ..., `<h6>`
* **Atividade 4:** `<p>`, `<b>`, `<i>`

* **Atividade 6:** `<ol>`, `<li>`

* **Atividade 11:** `<figure>`, `<figcaption>`
* **Atividade 12:** `<table>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>`
* **Atividade 13:** `<form>`, `<label>`, `<input>`, `<textarea>`, `<select>`, `<option>`
